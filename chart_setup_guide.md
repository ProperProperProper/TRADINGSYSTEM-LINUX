# Day Trading Chart Setup Guide

This document breaks down the specific technical setup and components used by the trader in the excerpt.

## 📊 Core Components & Settings

### 1. Anchored Volume Profile (AVP)
The trader uses the **Anchored Volume Profile (AVP)** drawing tool to analyze market auction dynamics. 

*   **Anchor Point:** `9:30 AM EST` (NYC Market Open). This calculates the volume distribution strictly from the start of the regular US trading session.
*   **Row Size Settings:** `2 Ticks`. This ensures ultra-high granularity, grouping the volume data in increments of 2 price ticks for precise level identification.

### 2. Chart Overlay Levels

| Visual Element | Meaning | Application |
| :--- | :--- | :--- |
| **Blue & Red Boxes** | **HTF SnR Levels** (High Timeframe Support & Resistance) | Drawn from macro charts (e.g., 1H, 4H, Daily) to identify major institutional turning points. |
| **Grey Boxes** | **Key Levels of Volume** (High Volume Nodes / POC) | Zones generated by the AVP where massive order execution occurred, serving as magnets or acceleration zones. |

---

## 🛠️ Replicating the Setup (e.g., TradingView)
1. Select the **Anchored Volume Profile** tool from the forecasting and measurement tools menu.
2. Click directly on the **9:30 AM** candle of the current session.
3. Open the AVP settings menu pane:
   * Change **Row Layout** to **Ticks**.
   * Set **Row Size** to `2`.
4. Manually plot your macro **Support & Resistance** zones (Blue/Red) and heavy AVP profiles zones (Grey).
