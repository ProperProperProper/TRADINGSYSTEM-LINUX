## Finish the online research ensemble and make it actually work

**Action taken:** `c98bee5` in the bot repo (2026-10-17 22:07).

**Problem and solution (commit message):**

Complete the work started in the previous session: retire the local Qwen
selector and drive the lab's hourly strategist from the checked OpenCode
free-model ensemble, with persistent, shared memory.

What changed and why
- Ensemble (research only, never places orders or changes exits):
  teacher_engine now asks distinct, least-loaded free OpenCode models until two
  name the same candidate. Fixes three defects that made the loop propose
  nothing:
  * `steps: 1` made most free models stop at the step limit and return an essay
    instead of the required JSON; the agent profiles now allow a few steps while
    every tool stays denied.
  * the prompt asked for a candidate *index* while the evidence listed *names*,
    so name answers failed to parse; a name, an index and null now all resolve,
    and the JSON is found even when wrapped in a "maximum steps" essay.
  * the parser only scanned the first/last brace; it now scans every balanced
    object and keeps the last usable one.
- Validation fallback: Claude first, then Codex; when a session is unavailable
  (weekly/quota/session limit, not signed in, missing binary) the fastest free
  model (`opencode/deepseek-v4.1-flash-free`) decides and approves via a new
  `online-validator` agent. A rejection from a working session is still final;
  the chosen validator is recorded. A deliberate "wait" skips validation.
- Fixes an OpenCode project-discovery bug: OpenCode resolves the project from
  the inherited `PWD`, which Rust's `current_dir` does not update, so every
  model failed with "Agent not found" when the lab ran from its runtime dir.
  The command now sets both cwd and PWD to the bot repo.
- Shared persistent memory: every model (proposer and validator) receives the
  same SQLite brain state, verified outcomes, option skills, recent actions and
  earlier model answers. Old `qwen_*` tables are migrated once and kept as an
  archive. Trimmed the agent blurbs and prompts to strategy decisions only.
- Docs (ONLINE_AI.md, BRAIN.md, README, STATE) updated for the new tables,
  shared memory and the fallback validator.

Verification
- Real end-to-end run of `brain run strategist` from the lab runtime dir: two
  free models agreed and the brain chose to wait; a synthetic probe returned
  `candidate=Some(0)` validated by `opencode/deepseek-v4.1-flash-free` (Claude
  was at its weekly limit, Codex unavailable).
- `cargo test` in lab: 293 passed. `cargo clippy --all-targets -- -D warnings`:
  clean. Bot repo: `cargo test --release` 200 passed; clippy clean.

Known limits
- Free public models are nondeterministic; some never emit parseable JSON. They
  are demoted by the failure score and cooled down; the ensemble waits rather
  than inventing a proposal when fewer than two models agree.
- No live/paper profit claim: only stored-candle walk-forward verdicts label
  winners. Exits are untouched.

- Ensemble (research only, never places orders or changes exits):
  teacher_engine now asks distinct, least-loaded free OpenCode models until two
  name the same candidate. Fixes three defects that made the loop propose
  nothing:
  * `steps: 1` made most free models stop at the step limit and return an essay
    instead of the required JSON; the agent profiles now allow a few steps while
    every tool stays denied.
  * the prompt asked for a candidate *index* while the evidence listed *names*,
    so name answers failed to parse; a name, an index and null now all resolve,
    and the JSON is found even when wrapped in a "maximum steps" essay.
  * the parser only scanned the first/last brace; it now scans every balanced
    object and keeps the last usable one.
- Validation fallback: Claude first, then Codex; when a session is unavailable
  (weekly/quota/session limit, not signed in, missing binary) the fastest free
  model (`opencode/deepseek-v4.1-flash-free`) decides and approves via a new
  `online-validator` agent. A rejection from a working session is still final;
  the chosen validator is recorded. A deliberate "wait" skips validation.
- Fixes an OpenCode project-discovery bug: OpenCode resolves the project from
  the inherited `PWD`, which Rust's `current_dir` does not update, so every
  model failed with "Agent not found" when the lab ran from its runtime dir.
  The command now sets both cwd and PWD to the bot repo.
- Shared persistent memory: every model (proposer and validator) receives the
  same SQLite brain state, verified outcomes, option skills, recent actions and
  earlier model answers. Old `qwen_*` tables are migrated once and kept as an
  archive. Trimmed the agent blurbs and prompts to strategy decisions only.
- Docs (ONLINE_AI.md, BRAIN.md, README, STATE) updated for the new tables,
  shared memory and the fallback validator.
